💬 ¿Qué es un PROMPT?

La instrucción o pregunta que le das a la IA para obtener una respuesta.

La IA es como un coche de Fórmula 1: si no sabes conducirlo, te estrella. Si sabes, adelantas a todos. Un prompt básico da resultados básicos — un prompt completo da resultados profesionales.

🧩 Los 3 pasos de un prompt efectivo

01 · IDENTIDAD
Dile a la IA quién debe ser. Ej: "Actúa como un maestro explicando a un principiante"
02 · INTENCIÓN
Dile qué quieres y para qué. Ej: "Quiero entender qué es la fotosíntesis de forma divertida"
03 · INSTRUCCIONES
Dile CÓMO lo quieres — aquí está el 80% del resultado. Ej: "En 3 puntos cortos, sin palabras difíciles"

📝 La plantilla — copia y rellena

IDENTIDAD: Actúa como [rol] especializado en [área].
INTENCIÓN: Quiero [resultado concreto] para [objetivo o contexto].
INSTRUCCIONES: Formato: [texto/lista/tabla] · Estilo: [sencillo/profesional/divertido] · SÍ quiero: [...] · NO quiero: [...]

🔧 El secreto del profesional: corregir en una frase

Escribe un buen prompt y luego corrige con frases cortas: "Más corto." · "Cambia el tono." · "Reescribe el segundo punto." La IA recuerda todo lo anterior — no tienes que empezar desde cero.

🛠️ Herramientas gratuitas para conversar con IA

Usa alguna de estas herramientas gratuitas para conversar con IA para las actividades prácticas:

  • ChatGPT (chat.openai.com) — el más popular, excelente para textos
  • Google Gemini (gemini.google.com) — integrado con Google
  • Microsoft Copilot (copilot.microsoft.com) — integrado con Bing

✏️ Actividad práctica 1 — Construye tu primer prompt

Usa la plantilla de 3 pasos para crear un prompt sobre algo que quieras aprender o hacer con la IA.

🔁 Actividad práctica 2 — Practica corregir como profesional

Escribe un prompt básico, luego uno mejorado con los 3 pasos, y practica corregirlo con una frase corta.

💭 Reflexión final

Puedes imprimir la guía para que te sirva de apoyo para el uso de las herramientas de IA.

3. ¿Cuál de estas es una IA conversacional gratuita?
